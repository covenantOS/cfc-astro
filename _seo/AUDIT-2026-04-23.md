## 3. Live technical findings (curl against cfc-astro.pages.dev)

### Good
- All 36 sitemap URLs → 200. No 5xx, no redirect loops.
- Canonicals correctly point to `https://www.customfabriccreations.net/...` on every page. Prevents the staging URL from competing for rankings pre-cutover.
- Meta robots: `index,follow,max-snippet:-1,max-image-preview:large,max-video-preview:-1` on every page. ✅
- `/api/contact/` POST → 303 redirect to `/thank-you/` in ~100ms. Cloudflare Pages Function wired correctly.
- `/favicon.svg`, `/robots.txt`, `/sitemap-index.xml` all 200.
- `_redirects` file properly configured with trailing-slash normalization + WP legacy paths (`/wp-admin/*`, `/author/*`, `/feed/`).

### Issues
- **`/images/og-default.jpg` → 404.** Ships as the default `ogImage` in `BaseLayout.astro:30`. Any page that doesn't set its own `ogImage` serves a broken social preview. Confirmed-affected pages: `/about/`, `/contact/`, `/brands/` (and likely more).
- **No `public/_headers` file.** Response headers are missing HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Permissions-Policy. Only `Cache-Control` and `Referrer-Policy` present. Not a ranking factor on its own, but weakens site trust signals and fails Lighthouse security best-practice checks.
- **robots.txt sitemap line points to `www.customfabriccreations.net/sitemap-index.xml`** on the staging deploy — cross-domain pointer. Harmless but redundant; update once live or leave as-is since canonicals already handle it.
- PageSpeed Insights API quota exceeded — couldn't pull CWV field data today. Re-run after DNS cutover with an API key.

## 4. Schema findings (9 issues)

### P0
1. **FAQPage schema not emitting on any service or area page.** Pipeline (`content.config.ts` → `[slug].astro` → layout → `BaseLayout` → `Schema.astro:244`) is fully wired — only missing piece is `faqs:` frontmatter in every content MD file (`grep -l "faqs:"` returns 0). Live WP `/services/plantation-shutters/` emits 18 Q&As as JSON-LD; Astro emits 0.
2. **`/about/` renders 4 FAQs visually but never passes `faqs` prop to `BaseLayout`.** Visible content exists; schema block never fires. Same pattern on homepage (5 default Q&As in `<FAQ>` component).
3. **Article `dateModified` hardcoded equal to `datePublished`.** `Schema.astro:193` — no separate prop. Any edit to guide posts leaves dateModified stale.

### P1
4. **No `AggregateRating` on LocalBusiness** despite "4.9 / 100+ reviews" used sitewide. Losing local-pack star-rating eligibility.
5. **No `founder: { name: 'Terry Popick' }` on LocalBusiness.** Breaks person-to-business entity connection for AI knowledge graphs.
6. **LocalBusiness address missing `streetAddress` and wrong `postalCode`.** Schema.astro:57–63 has locality/region/country/postalCode only. `postalCode: '33701'` is hardcoded (downtown). Confirmed West St. Pete address is **3026 Central Ave Ste 551, 33712**. No `streetAddress` anywhere in schema.
7. **`/brands/` uses `pageType="brands"` but `Schema.astro` has no handler** — brands page emits generic schema only (no `CollectionPage` node).
8. **No `sameAs` array on LocalBusiness** — no link to GBP, Facebook, Wikipedia, Yelp. Missed entity corroboration.

### P2
9. **Article pages should use `BlogPosting` (or `NewsArticle`) instead of bare `Article`** — matches Google's rich-result recommendations.
10. **No `WebPage` node on non-home pages** — minor missed signal linking page to WebSite.
11. **Hero video at `/hero-video.mp4`** has no `VideoObject` schema.
